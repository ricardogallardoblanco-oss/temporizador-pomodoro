# Temporizador

Temporizador y Pomodoro minimalista en un único archivo HTML, sin dependencias ni instalación. Ábrelo en el navegador y reduce la ventana para usarlo como widget.

## Funciones

- Hora actual siempre visible
- Cuenta atrás por **duración** (h / min / s) o **hasta una hora concreta**
- **Pomodoro** con enfoque, descanso, descanso largo y número de ciclos configurables; las fases pueden encadenarse automáticamente
- Aviso sonoro al terminar y tiempo restante en el título de la pestaña
- Tema **claro / oscuro**
- **Interfaz colapsable**: solo hora y cuenta atrás
- Se adapta al tamaño de la ventana; en ventanas pequeñas los controles aparecen al pasar el ratón
- Recuerda el tema, los ajustes del Pomodoro y el estado colapsado

## Uso

Abre `index.html` en el navegador. No necesita servidor ni conexión a internet.

## Atajos de teclado

| Tecla | Acción |
|---|---|
| `Espacio` | Iniciar / pausar |
| `R` | Reiniciar (con el temporizador parado en modo Pomodoro, reinicia la serie) |
| `N` | Saltar a la siguiente fase del Pomodoro |
| `1` `2` `3` | Modo duración / hora de fin / Pomodoro |
| `C` | Colapsar / expandir la interfaz |
| `T` | Cambiar tema |
